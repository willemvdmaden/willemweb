Taxonomy of LLM self-explanations: reference sheet

The taxonomy characterizes the explanation as delivered to the user, in its content, form, and presentation. It is restricted to properties that can be configured without modifying the model, whether through the prompt, the surrounding pipeline, or the interface.

7 dimensions, 28 subdimensions.

How to read this sheet

  • Dimension: a group of related properties. There are 7. Example: Surface.
  • Subdimension: one property. There are 28. Example: length.
  • Characteristic: one of the few options a subdimension sorts an explanation into, exactly one of which applies. Example: short, medium, long for length.

Reading the example pairs. Each dimension page shows two examples built from the same baseline, which differ only on the subdimensions of that dimension. Labels at the top of each example give its characteristic on each subdimension; shaded phrases in the text show where each subdimension appears.

Surface covers how the explanation looks on the page before its content is read: how much text there is, what kind of words it uses, how it is laid out, and how much detail each reason gets.
