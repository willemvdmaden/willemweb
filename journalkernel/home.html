Your data

Entries, reflections, and kernel memory are stored only in this browser — nothing journal-related ever touches a server. That also means this browser is the only copy: clearing site data deletes it, private windows don't keep it, and Safari deletes script-written storage for sites you haven't visited in 7 days. Download a backup now and then.

Clear this browser's journal data

Permanently deletes every entry, reflection, and the kernel memory stored in this browser for your account. Since your journal lives only here, this cannot be undone — download a backup first.
